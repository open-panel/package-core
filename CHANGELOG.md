# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0]

### Added

- `Logger` with a bounded ring buffer, pluggable sink, and recursive secret
  redaction.
- `ProfileRuntime`: button-press → action resolution, page-change → device
  render, calibration mode and hotkey-switch state tracking.
- Button/page/calibration image generators.
